# Viagem pelo Mundo — Blog de Viagem

Projeto acadêmico em HTML5, CSS3 e JavaScript puro.

## Páginas
- `index.html` — Home
- `destinos.html` — Destinos
- `roteiros.html` — Roteiros
- `dicas.html` — Dicas de Viagem
- `contatos.html` — Contatos

Abra `index.html` no navegador para visualizar. Para publicar, envie todos os arquivos ao GitHub e ative o GitHub Pages.

As imagens são carregadas externamente do Unsplash. O formulário de contato é demonstrativo e não envia mensagens a um servidor.
